FAQ

Got questions?

Everything you need to know about Alone Auth.
How fast can I get started? ▼
Under 5 minutes. Create a Sheet, paste the ID, download the SDK, call login(). That's it.
Is it really free? ▼
Yes. No subscriptions, no hidden fees. Google Sheets provides the free tier. You only pay Google if you exceed their limits.
Which languages are supported? ▼
C++ (single-header), C# (single-file), Python (module). All three share the same API and backend.
What is HWID binding? ▼
Hardware ID binding locks a user to a specific machine. The client sends volume serial + machine name + MAC address on login.
Do I need to deploy a server? ▼
No. The backend is Google Apps Script — deploy once as a web app and you're done. No VPS, no database, no Docker.

Version Check

—

Change this name when you release a new build. Client apps compare their local version against this — if different, they'll prompt users to update.

C++

Drop auth.h into your project, #include "auth.h", call gk_auth::login().

main.cpp
#include "auth.h"
int main() {
    std::string sid = "YOUR_SHEET_ID", u, p;
    std::string app_ver = "1.0";  // ← change on new build
    std::string sv = gk_auth::checkUpdate(sid);
    if (!sv.empty() && sv != app_ver) {
        std::string m = "Update: \"" + sv + "\" available";
        MessageBoxA(0, m.c_str(), "Update", MB_OK|MB_ICONINFORMATION);
    }
    std::cout << "User: "; std::getline(std::cin, u);
    std::cout << "Pass: "; std::getline(std::cin, p);
    if (gk_auth::login(sid, u, p)) std::cout << "GRANTED\n";
    else                           std::cout << "FAILED\n";
}

C#

Add auth.cs, call GkAuth.Auth.Login(). Requires System.Text.Json.

Program.cs
using GkAuth;
var sid = "YOUR_SHEET_ID";
var sv = Auth.CheckUpdate(sid);
if (!string.IsNullOrEmpty(sv) && sv != Auth.AppVersion)
    Console.WriteLine("Update: \"" + sv + "\" available");
Console.Write("User: "); var u = Console.ReadLine();
Console.Write("Pass: "); var p = Console.ReadLine();
if (Auth.Login(sid, u, p)) Console.WriteLine("GRANTED");
else                       Console.WriteLine("DENIED");

Python

Put auth.py in your project, from auth import login. Requires requests.

main.py
from auth import login, check_update, APP_VERSION
sid = "YOUR_SHEET_ID"
sv = check_update(sid)
if sv and sv != APP_VERSION:
    print(f'Update: "{sv}" available')
u = input("User: ")
p = input("Pass: ")
if login(sid, u, p): print("GRANTED")
else:                print("DENIED")
